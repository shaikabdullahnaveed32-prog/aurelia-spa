# Aurelia Spa

A fully functional, modern spa and wellness website designed to provide a premium, calm, and elegant online experience.

## Overview

Aurelia Spa is a fully functional responsive website created for a luxury spa brand. The project focuses on clean visual design, smooth user experience, and presenting spa services in a professional way.

## Features

* Fully functional website
* Modern luxury spa design
* Responsive layout for desktop and mobile
* Services and treatment sections
* About section
* Contact and booking-focused sections
* Smooth navigation
* Premium visual presentation
* Clean and minimal user interface
* Backend integration with Supabase

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend / Database: Supabase
* Deployment: Netlify

## Live Website

https://aureliaspa56.netlify.app/

## Project Goal

The goal of this project was to build a fully functional spa website that feels like a real business website rather than a basic template.

The design focuses on usability, performance, presentation, and creating a premium brand experience.
